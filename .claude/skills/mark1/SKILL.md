# /mark1 — Full Mark 1 Activation

**Activate the complete Mark 1 operating doctrine.**

## What It Does

Loads and confirms the full system online:
- **Router (κ-gate):** Is a cheap exact verifier available? Draw weapon / armor-only / escalate
- **Arsenal:** 12 weapons (each domain-specific, verifier-gated)
- **Kit:** 8 accessories (gloves, shield, shoes, vault, triage, crucible, bootstrap, composeauth)
- **Helmet:** Multi-front orchestrator for hard problems (Provost → Registrar → Departments → Dean)
- **EQUIP:** Loadout selector (reads task → picks style → equips that loadout)

## The Discipline

- **Never claim to solve an open problem** without machine-verified proof
- **Verify independently** (different model or machine check, never self-report)
- **Ground load-bearing facts** (fetch/run, don't assert)
- **Only draw a weapon when a verifier exists** (κ-gate)
- **Escalate to Helmet only when ≥2 styles tie** (avoid false confidence)
